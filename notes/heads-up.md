# Heads-Up No-Limit

# Preflop Strategy

## Facts

* BTN is also SB
* BTN/SB acts first preflop but last postflop

##  Strategy for 100bb effective stack

### BTN/SB open

* Open Size 2.25x
* Open Range
  * 84% of hands
  * fold J~3/2o, T~6/3o, 9~8/4o

### BB defense facing open

* Defending tighter range for bigger size
* Defending 75% range for 2.25x open
* For 2.5x open 
  * 3Bet - polarized
    * value: 77+(all pairs for deeper than 100bb), ATs+, AJo+
    * bluff: suited gap connectors, 86s, T7s, 75s
    * size: 2.7x
  * Call
    * 66-
    * suited connectors, J9s, T9s
    * off-suited high cards, KTo, QJo, QTo

### BTN/SB defense facing 3 bet

  * Calls
    * low pocket pairs
    * strong and medium suited connectors

  * 4-Bet
    * bluff:
      * off-suit high cards, AT,KQ,QT,JT
      * weak KXs/QXs
      * AQ/9/5o
      * weakest suited connectors

# Postflop strategy

* Tip1: Use 1 size consistently for flop and turn, and 2 sizes for river
  * OOP: block 1/4~1/3 and value 2/3
  * IP: small 2/3 and value 1.5x or allin

* Tip2: Need to have complete non-equity bluff to barrel off
  * Hands that unblock folding range(like draws) against the board
    * A2o , 22, 43s
  * OOP need more equity to bluff

* Tip3: Think about bluff candidate why doing value bet on river

## Side topics
### Bet size adjustment according to position and player type
* Bigger size as IP, since IP has more win rate, so win more
* Bigger size as OOP, because it could cut down the odds of IP player,if the IP could fold marginal hands, so it works with tight player and passive players, but not loose and aggresive ones
* This thinking also applies to 3bet, 4bet, 5bet
